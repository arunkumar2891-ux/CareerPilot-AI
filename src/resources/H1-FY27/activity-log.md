# H1 FY27 Activity Log

## How to Use
- Ask the agent to "log" an activity anytime (e.g., "Log: Led design review for XDR detection engine")
- Each entry captures: date, category, description, impact, and collaborators
- At review time, ask the agent to "summarize my activities" or "generate review bullet points"
