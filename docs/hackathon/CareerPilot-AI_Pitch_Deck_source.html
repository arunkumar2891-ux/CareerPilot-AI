Problem Statement

Job seekers redo the same manual work for every opening, every day.

01

Search is repetitive

Listings live on job boards. A candidate re-runs the same searches, skims duplicates, and loses track of what they have already seen.

02

Tailoring is slow

Each role needs a resume rewritten against its description and shaped to pass an applicant tracking system (ATS), usually by hand.

03

Tools fabricate

Generic AI resume tools inflate keyword scores by inventing employers, metrics, and skills, leaving a document the candidate cannot defend in an interview.

The cost is not only time. It is applying to the wrong roles, or sending a resume that does not hold up.

Why It Works

Three design decisions make it trustworthy enough to leave running.

1

Match gate before the rewrite

The AI spend goes only to jobs above the candidate's own minimum score. Weak matches stay on the board with their score.

2

Grounded resumes

The prompt and a separate validator agree on one contract. Employers, dates, metrics, and skills must trace to the source resume, or the output is rejected.

3

A real off switch

Pausing the schedule stays paused. Cost and email volume are opt-in, and the candidate reviews every resume before anything is sent.

Google AI Tools and Models

Gemini is the engine today. The buildathon extends it to files and voice.

In production

Gemini API

Model gemini-3.6-flash scores each job against the master resume, rewrites the resume into the ATS contract, drafts cover letters, and writes the interview brief. A second Gemini key is the automatic fallback.

Planned

Gemini Omni

Read an uploaded PDF resume or a screenshot of a job posting into the same master-resume corpus, so setup needs no retyping.

Planned

Gemini Live

Spoken interview rehearsal on top of the brief the API already writes, with follow-ups drawn from the candidate's real resume.

Planned

Google AI Studio

Design and evaluate the prompts for scoring, the ATS contract, cover letters, and interview briefs.

Planned

Google Antigravity

Build the scheduled agent steps: search, score, stop or tailor, PDF, summary.

Planned

Google Agent Skills

Package each stage as a reusable skill so the loop can be extended per market or per cohort.

Deploy and Scale on Google Cloud

One service per stage, so a long search never sits inside one request.

Compute

  • Cloud Run: start a run, process one job, copilot
  • Cloud Tasks: per-job queue, claimed once so retries never double-tailor
  • Cloud Scheduler: daily tick, active automations only

AI

  • Vertex AI: Gemini API, Omni, Live under one quota and log project
  • AI Studio prompts promoted to versioned Vertex prompts

Data and edge

  • Cloud SQL for PostgreSQL: users, jobs, runs
  • Cloud Storage: PDFs
  • Secret Manager: keys
  • Firebase Hosting: React app

Scaling: Cloud Run and Cloud Tasks fan out per job and scale to zero between runs. A bootcamp cohort is the same services with a higher Vertex quota. The product runs today on Supabase and the Gemini API; this is the migration path.
